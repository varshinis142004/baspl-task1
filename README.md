# BASPL - Basic Authentication System with Python and JavaScript

This project is a simple user authentication system featuring user registration and login. The backend is built with Python and Flask, while the frontend uses vanilla JavaScript, HTML, and CSS.

## Project Structure

The repository is organized into two main directories:

-   `baspl/front/`: Contains all frontend files, including HTML, CSS, and JavaScript.
-   `baspl/back/`: Contains the backend Flask application and the SQLite database.

## Getting Started

To run this project, follow these steps:

### Prerequisites

-   Python 3.x
-   pip

### Installation and Running

1.  **Navigate to the backend directory:**
    ```bash
    cd baspl/back
    ```

2.  **Install the required packages:**
    ```bash
    pip install Flask
    ```

3.  **Run the Flask application:**
    ```bash
    python app.py
    ```

4.  **Open your browser** and go to `http://127.0.0.1:5000` to view the application.
